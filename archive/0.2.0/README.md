# TNLearn 0.2.0 documentation snapshot

The pages, examples, and media in this directory come from documentation
commit `3ac0edf182ad2c08b1f40fd3b90adef04d03ce09`, before the 0.2.1.dev0 update.
They document library commit `0ae14184a0e15bca352eb8a22c6ca6a005ba4a8a` (0.2.0).

The main Sphinx build publishes this snapshot at `0.2.0/`, with independent
navigation, API indexes, search, and example downloads. No Git checkout or
network access is needed during the build.

Only cross-version links and build instructions are adapted to the snapshot's
new location. Presentation and version controls use the current shared theme.
Development features must be documented in the main `source/` tree, not here.
