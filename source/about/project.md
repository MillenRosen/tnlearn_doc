# Project and contributors

TNLearn is an open-source Python library for discovering task-based neurons
and building neural networks from their aggregation formulas. It connects
symbolic regression, trainable parameterization, and neural-network training.

## Project links

- [Library source and releases](https://github.com/NewT123-WM/tnlearn)
- [TNLearn on PyPI](https://pypi.org/project/tnlearn/0.2.0/)
- [Documentation repository](https://github.com/MillenRosen/tnlearn_doc)
- [Library issues](https://github.com/NewT123-WM/tnlearn/issues)
- [Documentation issues](https://github.com/MillenRosen/tnlearn_doc/issues)

For a usage issue, include the package versions, expression, constructor
settings, input shapes, and a small reproducible example. Avoid including
provider credentials in LLM reports.
