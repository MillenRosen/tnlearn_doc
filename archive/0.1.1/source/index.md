# TNLearn 0.1.1

This archive preserves the early documentation of simplified vectorized
symbolic regression, task-based neurons, and the original MLP interface.
Its benchmark results, background explanations, and API examples belong to
that historical documentation.

The current release is **0.2.0**. Its `mode='legacy'` follows the simplified
vectorized formulation and includes later extensions, so it is not identical
to the 0.1.1 package. Use the version selector to return to the current API.
