TNLearn package paper assets
===========================

Paper: TNLearn: An Open Source Python Package for Task-based Neurons
Preprint: https://arxiv.org/abs/2609.27564
Authors: Meng Wang, Tieyun Li, Juntong Fan, Hanyu Pei, Jing-Xiao Liao,
         Yaodong Yang, Jianwei Ma, and Fenglei Fan.

The original SVG files were supplied by the project author in the workspace's
svg/ directory. They are copied unchanged, including the embedded diagrams.net
source and the native adaptive light/dark colors.

Supplied filename                          Documentation name
framework2.drawio.svg                       framework.svg
GPSymRegressor2.svg                         gp.svg
LLMSymRegressor-innerproduct2.svg            llm.svg
rlregressor-innerproduct2.drawio.svg         rl.svg
polyregressor.drawio.svg                    polytensor.svg

The separately supplied arxiv_preview.pdf is preserved as tnlearn-paper.pdf.
Its TeX source in jmlr_arxiv_upload_clean_20260922.zip informs the explanations.

The paper's PolyTensor diagram includes a periodic branch not implemented by
PolyTensorRegressor 0.2.0. The method page explains the difference.
